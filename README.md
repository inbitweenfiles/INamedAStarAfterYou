# I NAMED A STAR AFTER YOU

A fun project designed so that you can virtually gift a star to people based on the unique star traits and color.

## Tech Stack

HTML
CSS
Javascript
Vite
Google Sheet (Email Collection) 

## Getting Started/ Installation

Make sure you have Node.js and npm installed. This project uses npm 9.5 and Node.js v18.15.
1. Clone this repository
git clone <your-repo-url>
2. Navigate to the project directory
cd <project-folder>
3. Install dependencies
npm install
4. Start the development server
npm run dev
5. Open the local URL provided by Vite in your browser.
